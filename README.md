# QuizMaster — React Quiz App ⏱️

**Description**  
QuizMaster is a modern and interactive quiz application built with React.  
It challenges users with multiple-choice questions and includes a built-in **countdown timer** for each question to make it more exciting.  
This project is inspired by Jonas Schmedtmann’s React course and demonstrates component-based architecture, React hooks, and state management.

---

## 🚀 Features

- 🎯 Multiple-choice questions  
- 🕒 Timer for each question (automatic move when time runs out)  
- ✅ Instant feedback after answering  
- 🧮 Final score summary at the end  
- 🔁 Restart quiz option  
- 💾 Optionally loads questions from a JSON file or API  
- 📱 Fully responsive design  

---

## 🧱 Tech Stack

- **React** (functional components + hooks)  
- **React Hooks:** `useState`, `useEffect`, `useReducer` (if used)  
- **CSS / Styled Components** for UI styling  
- **Local JSON / API** for question data
